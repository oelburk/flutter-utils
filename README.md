# 🛠️ Flutter Utilities

✨ A collection of utilities for Flutter and Dart development to make your development workflow smoother and more efficient!

## 📋 Contents

### 🔧 Scripts

- 📦 `pubspec_lock_check.sh` - Lists dependencies from the pub spec.lock file if they have newer versions available

### 🎯 Dart Tools

- 📝 **[Markdown to Notion Converter](dart/markdown-to-notion/)** - Convert Markdown files to Notion-compatible format
  - 🚀 Converts headers, text formatting, lists, links, code blocks, and tables
  - 💻 Command-line tool with simple usage
  - 📄 Includes comprehensive examples and test files

## 🚀 Getting Started

Each utility includes its own documentation and usage instructions. Navigate to the specific tool directory for detailed setup and usage information.
